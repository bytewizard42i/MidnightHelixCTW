## Draper 60-second pitch

Source: pre-existing entrant-owned HelixCTW local media, intentionally not
included in this public repository.

Technical metadata:

- Duration: 59.968 seconds
- Video: H.264, 1920 x 1080
- Audio: AAC, stereo, 48 kHz

Local transcription:

```text
HelixCTW is a privacy-preserving data protocol designed for a world where
sensitive information must remain secure but still useful.

Today, organizations are forced to choose between fast access to data and
meaningful privacy.

By combining Midnight's zero-knowledge technology, Filecoin's decentralized
storage, CockroachDB's globally distributed database infrastructure, and the
DIDz network framework, HelixCTW creates a secure layer for identities,
real-world assets, medical records, supply chains, and private Ai.

Our hot and cold storage architecture allows encrypted information to be
available across global networks, while users provide specific facts without
exposing underlying data.

Instead of giving artificial intelligence unrestricted access to private
records, HelixCTW lets Ai agents query authorized information through controlled
privacy-preserving permissions.

HelixCTW is not simply another database. It is a reconstructible, verifiable
cache of truth.
```

Best retained language:

- Sensitive information must remain secure but still useful.
- The agent queries an authorized fact instead of receiving the private record.
- HelixCTW is not another database; it is a reconstructible, verifiable memory
  layer.

Claims requiring live evidence before reuse:

- encrypted information available across global networks;
- Filecoin as an active submission dependency;
- real zero-knowledge permission enforcement; and
- general applicability to every listed domain.
