# Hackathon video plan

Target runtime: 2 minutes 35 seconds to 2 minutes 45 seconds.

The final video must show the application functioning. Vision slides may explain
the architecture briefly, but they cannot substitute for live memory evidence.

> **Recording gate, 2026-08-14:** Do not record or publish the execution script
> while the public URL is absent or any depicted live provider lacks current
> receipt evidence. Remove or visibly relabel an unavailable segment rather than
> simulating it. The current source-only UI and disconnected providers do not yet
> satisfy this gate.

## Script

### 0:00 to 0:15, the problem

Visual: a sealed synthetic deed and the question, **Is this property
unencumbered?**

Narration:

> An Ai agent needs the answer, but it should not receive the deed. HelixCTW
> remembers what matters, proves the permitted fact, and leaves the private source
> sealed.

### 0:15 to 0:45, Session A writes durable memory

Visual: start the Morrow case and store the privacy-safe title-review plan.

Show:

- CockroachDB session and event identifiers;
- safe summary and vector model;
- `DIDz: MOCK`, `AgenticDID: MOCK`, `RWAz: MOCK`;
- synthetic-data badge.

### 0:45 to 1:15, a fresh agent recalls

Visual: close Session A, visibly start Session B, ask where the work stopped.

Show:

- recalled source-session and memory IDs;
- semantic distance;
- exact property identifier;
- no browser-state dependency.

### 1:15 to 1:45, private proof and minimum disclosure

Visual: run the approved question.

Show:

- `scope authorized: YES`;
- `verified predicate: UNENCUMBERED`;
- `private source text disclosed: NO`;
- Midnight test-network receipt;
- CockroachDB action receipt.

Narration:

> Midnight verifies the private commitment. CockroachDB preserves the memory,
> exact state, and receipt. The agent receives the answer, not the document.

### 1:45 to 2:05, refusal

Visual: request the complete deed and owner identifiers.

Show:

- denial reason;
- zero protected fields disclosed;
- durable denial receipt;
- state unchanged.

### 2:05 to 2:28, reconstruction

Visual: rebuild a new disposable recall projection, verify its manifest, switch
the active generation, and repeat the query.

Show the same memory ID and predicate after rebuild. State clearly that canonical
records were preserved and this is not a full-cluster disaster-recovery claim.

### 2:28 to 2:42, inspectability and close

Visual: read-only Managed MCP verification and compact architecture diagram.

Narration:

> HelixCTW is reconstructible private memory for Ai agents. It remembers across
> sessions, discloses only the proved fact, and makes every result inspectable.

End card:

> The agent found the answer. It never saw the deed.

## Recording checklist

- public URL and public repository visible;
- guided-demo start and truthful provider lock state visible before any live
  operation;
- browser voice status is shown honestly; the recording does not rely on Web
  Speech as its only narration or caption source;
- captions burned in or uploaded;
- large readable text at 1080p;
- no copyrighted music;
- no secrets, console tokens, private account IDs, or personal browser chrome;
- release commit and provider labels visible;
- no claim lacking a current receipt;
- final public YouTube or Vimeo runtime under three minutes.
