# End-to-End Test Contract

The public workflow is complete only when automated and manual checks prove:

1. Session A closes successfully.
2. A fresh Session B has no browser chat history.
3. Session B retrieves Session A memory from CockroachDB.
4. A semantic paraphrase recalls the expected memory through a real vector
   index.
5. Exact relational state is checked after vector recall.
6. The permitted one-bit predicate returns a real Midnight test receipt.
7. The private deed request returns no protected fields.
8. Replaying an idempotency key does not repeat effects.
9. A shadow projection rebuild preserves the canonical commitment.
10. Corrupt rebuild input cannot become active.
11. Managed MCP verifies allowlisted facts in read-only mode.
12. No subsystem silently falls back to a mock.
